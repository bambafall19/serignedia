Portfolio immersif de **Serigne Mbacké Dia** — étudiant & entrepreneur, CEO de **ARTAVECMOI** (startup qui transforme les photos en dessins sur papier et en cover art).

## 🎨 ARTAVECMOI
Startup d'art qui refait des photos en dessins sur papier et en cover art : portraits, cover de musique, commandes personnalisées.

## 🚀 Stack
- **React 19 + Vite** (app frontend dans `app/`)
- **Framer Motion** — animations & micro-interactions
- **Web Audio API** — feedback sonore synthétisé (survol/clic)
- Images optimisées en **WebP**

## 📦 Lancer le projet
```bash
cd app
npm install
npm run dev -- --port 1000
```

## 🌐 Serveur dev
http://localhost:1000
